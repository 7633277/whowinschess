Privacy Policy

WhoWinsChess Pipeline is an internal tool used by the owner of the WhoWinsChess YouTube channel to upload videos to that channel and to read that channel's own analytics.

What data is accessed

Through the YouTube Data API and YouTube Analytics API, the tool accesses only the channel owner's own account: video uploads, video metadata, and aggregate analytics reports for the WhoWinsChess channel. It does not access data of any other YouTube user, viewer, or channel.

How data is used and stored

Analytics data is stored locally on the channel owner's computer to understand which videos perform well. It is not shared, sold, or transferred to any third party. No personal data about viewers is collected.

Who can use the tool

The tool is not offered to the public. Only the channel owner authorises it, with their own Google account.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
